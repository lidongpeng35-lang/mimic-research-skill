# Roadmap

Priority is limited to improving MIMIC-IV extraction SQL quality.

1. Expand validated definition coverage and provenance.
2. Improve natural-language acceptance cases for cohort, window and aggregation ambiguity.
3. Add SQL golden cases for common ICU research patterns.
4. Strengthen static checks for join multiplicity, ICD versioning, specimen/unit ambiguity and time anchors.
5. Increase publication-grade validation of high-frequency concepts.

Out of scope: MCP servers, database executors, patient-data preview/export services, eICU, statistical modeling and causal inference.

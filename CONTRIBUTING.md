# Contributing

Contributions are welcome through issues and pull requests.

For a new or changed clinical variable, include: concept name/aliases; source product/schema/table/view; code/itemid/column and version; specimen/method/unit where relevant; time semantics; transformation/aggregation logic; provenance; at least one regression/acceptance case; and expected failure behavior when the source is absent.

Clinical-definition changes should be reviewable independently of code style changes. Do not submit patient rows, credentials, or exported datasets.

# Severity scores and composite indices

Composite scores are algorithms, not single variables. Prefer a versioned MIT-LCP MIMIC Code implementation when it matches the study. Record the exact derived-view version/commit and time semantics.

Examples include SOFA, SAPS II, OASIS, LODS, Charlson, and study-specific composites. Never substitute a simplified proxy while retaining the official score name. For SOFA in particular, cardiovascular points depend on hypotension/vasopressor criteria and dose; respiratory points depend on oxygenation/respiratory-support semantics. Validate each component and missing-data rule.

QC: component availability, time window, worst-vs-first aggregation, treatment-dependent components, unit conversion, missing component policy, and agreement with a trusted implementation on a test cohort.
